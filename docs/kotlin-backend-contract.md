# Scheduler API compatibility inventory

All paths below are relative to `/api`. Only registration and login are public. Other requests require a bearer JWT signed with HS256. The claims carry numeric `sub` (user ID), `email`, `iat`, and `exp` (seven days after issue).

| Resource | Routes | Request and response |
|---|---|---|
| Auth (4) | `POST /auth/register`, `POST /auth/login`, `GET /auth/me`, `POST /auth/change-password` | Register: `email,password,name` → 201. Login: `email,password` → 200. Both return `accessToken,user{id,email,name}`. Me returns the active user with timestamps. Password change takes `currentPassword,newPassword` and returns 200 `{ok:true}`. |
| Tasks (6) | `GET /tasks`, `GET /tasks/range`, `GET /tasks/categories`, `POST /tasks`, `PATCH /tasks/:id`, `DELETE /tasks/:id` | Daily `date`: position and creation order. Range `from,to`: date and creation order. Categories accepts optional `month`; newest casing wins. Create takes `title,date,category?,startTime?,endTime?,parentTaskId?`. Patch also accepts `completed,isChore,highPriority,top3Order,position,memo,subItemId` and excludes `parentTaskId`. |
| Recurring (3) | `GET /recurring`, `POST /recurring`, `DELETE /recurring/:id` | Create takes `title,category?`. Active sources sorted by creation. |
| Weekly (3) | `GET /week-items`, `POST /week-items`, `DELETE /week-items/:id` | List filters inclusive week starts by `from,to`. Create takes `weekStart,title,category?,days?`; weekday offsets are comma-separated 0–6. |
| Period (3) | `GET /period-items`, `POST /period-items`, `DELETE /period-items/:id` | List filters overlap with `from,to`. Create takes `startDate,endDate,title,category?`, including same-day periods. |
| Monthly memos (3) | `GET /month-memos`, `PUT /month-memos`, `DELETE /month-memos/:id` | List by `month`, category ascending and date/creation descending. Save takes `id?,date,category,content`. Missing ID creates a separate memo; blank content returns `{ok:true,deleted}`. Missing or foreign ID returns `{ok:false}`. |
| Memo items/folders (8) | `GET /memo-items`, `POST /memo-items`, `PATCH /memo-items/:id`, `DELETE /memo-items/:id`, `GET /memo-items/hidden-folders`, `POST /memo-items/rename-folder`, `POST /memo-items/delete-folder`, `POST /memo-items/copy-to-next-month` | List by `month`, category/position/creation order. Create takes `month,category,text,parentId?`; patch takes `text,content,assigned,completed,position`. Hidden folders return an array of category strings. Rename takes `month,from,to`; hide takes `month,category`. Copy takes `month,category?,excludeCompleted?,itemIds?` and returns `{ok:true,copied,nextMonth}`. |
| Memo item logs (5) | `GET /memo-item-logs`, `GET /memo-item-logs/labels`, `GET /memo-item-logs/units`, `POST /memo-item-logs`, `DELETE /memo-item-logs/:id` | All reads take `memoItemId`, list also takes `from,to`. List: date and creation descending; labels sorted; units most recently used first. Create takes `memoItemId,date,label,count,unit`. |
| Mind topics (4) | `GET /mind-topics`, `POST /mind-topics`, `PATCH /mind-topics/:id`, `DELETE /mind-topics/:id` | List and create accept the month/week key `month`. Create takes `name`; patch takes `name,isFolder,content`. List ordered by creation. |

POST routes return 201 except login and password change. GET, PATCH, PUT, and DELETE return 200 on success. Deletes return JSON. A missing task delete or missing task, memo item, or mind topic patch returns the corresponding legacy 404. Collection results are arrays. Tasks serialize `isChore`, topics serialize `isFolder`, and timestamps serialize in UTC with milliseconds. Optional PATCH fields retain their previous values when omitted and nullable fields clear on explicit null. Date-only values use YYYY-MM-DD and time-box values use HH:mm.

The [version 1 schema](../backend/src/main/resources/db/migration/V1__legacy_schema.sql) records all ten legacy tables. Materialization honors source creation dates and inclusive boundaries, and counts soft-deleted rows as existing occurrences. Task completion updates the corresponding memo item and recomputes parent completion. Folder operations are scoped by user and month. Copy remaps parent IDs and reuses matching target rows.
